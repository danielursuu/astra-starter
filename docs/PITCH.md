# Pitch și demo

## Pitch de 60 de secunde

| Secunde | Ce spuneți | Notițe |
|---|---|---|
| 0–10 | **Problema**, printr-o persoană concretă: „Ana pierde 5 ore pe săptămână cu …” | |
| 10–20 | **Soluția**, într-o propoziție. | |
| 20–45 | **Demo**: drumul principal, de la început la rezultat. | |
| 45–55 | **De ce contează**: cine plătește, metrica de impact, de ce acum. | |
| 55–60 | **Ce urmează** și ce cereți (feedback, utilizatori de test, mentori). | |

Spuneți la final, pe scurt, ce ați construit în 24 de ore (jurnalul din `PROGRESS.md` vă ajută).

## Lista pentru demo

- [ ] Demo-ul a fost repetat de 3 ori, cap-coadă, pe laptopul de prezentare.
- [ ] Datele de demo sunt pregătite și realiste.
- [ ] Merge fără internet sau aveți un hotspot de rezervă.
- [ ] Conturile sunt deja logate; parolele nu apar pe ecran.
- [ ] Textul e mare și se citește din fundul sălii.
- [ ] Notificările sunt oprite.
- [ ] O singură persoană vorbește în timpul demo-ului, alta dă click.

## Demo de rezervă

Dacă ceva cade în timpul prezentării:

- [ ] Un video de 30–60 de secunde cu demo-ul care merge (înregistrat cu cel puțin 2 ore înainte).
- [ ] Capturile de ecran din `docs/screenshots/`, în ordine.
- [ ] Propoziția pregătită: „Vă arătăm înregistrarea făcută azi la ora …”
