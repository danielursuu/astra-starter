# Date reale

Puneți aici 5–20 de exemple reale pe care trebuie să le proceseze produsul: documente, poze, tabele, texte, loguri.

- Includeți și un exemplu „urât” (scanat strâmb, incomplet, cu greșeli). Acolo se strică de obicei lucrurile.
- Fără date personale reale (nume, CNP, telefoane, adrese) dacă nu sunt anonimizate.
- Dacă fișierele sunt mari sau private, nu le puneți în git; descrieți aici de unde se iau.
